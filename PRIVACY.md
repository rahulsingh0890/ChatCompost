# Privacy Policy — ChatCompost

**Last updated:** September 28, 2026

## Data Collection

ChatCompost **does not collect user data for the developer or third parties**. No personal information, conversation content, browsing history, or usage analytics are gathered.

## How It Works

The extension runs entirely in your browser. It adds checkboxes to your ChatGPT conversation list, allowing you to select and delete multiple chats at once. The extension uses your existing ChatGPT session to send deletion requests directly to ChatGPT. Selected conversation IDs are stored in your browser’s session storage.

## Data Sharing

The extension sends requests only to ChatGPT to carry out the deletions you confirm. It does not send data to the developer, analytics providers, or advertising networks.

## Permissions Used

| Permission | Purpose |
|---|---|
| `activeTab` | Access the current ChatGPT page to add checkboxes and delete selected conversations |
| Content script matches (`chatgpt.com`, `chat.openai.com`) | Run the extension on ChatGPT websites |

These permissions are used only to provide the conversation selection and deletion features.
