# ChatCompost icon

The logo was cleaned with the built-in image editor to remove its cream background
and external shadow. The red circular minus design is retained. All PNGs have
transparency: `logo.png` is 128 × 128, with 16, 32, and 48 pixel variants for Chrome.

Prompt used:

> Use case: background-extraction. Edit target: the supplied ChatCompost Chrome extension logo. Remove only the cream/off-white background outside the circular red logo and remove its external ground/drop shadow. Make everything outside the circular logo genuinely transparent (alpha channel), not a white or checkerboard backdrop. Preserve the existing red circle, dark red border, glossy red shading, centered white horizontal minus bar, proportions and colors closely. Center the circular symbol on a square canvas with a small even transparent margin. This is the same existing icon cleaned up, not a redesign. No new details, no text.
